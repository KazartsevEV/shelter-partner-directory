# Nomad360 · локализация L0–L6

Источник требований: [карта проекта](../nomad360-codex-task-map.md#задача-4-полная-локализация-ru--en--kk) и [утверждённые подзадачи L0–L6, Issue #101](https://github.com/KazartsevEV/shelter-partner-directory/issues/101). Эта папка хранит материалы существующего плана, не заменяет его новой очередью.

14 октября 2026: задача 3 принята, PR #134 объединён (`9e5a7f51`), публикация подтверждена SHA256-паритетом 25 assets. Задача 4 выполняется **целиком L0–L6 в одном Draft [PR #135](https://github.com/KazartsevEV/shelter-partner-directory/pull/135)**. L0–L5 реализованы; L6 проходит итоговый CI и ожидает пользовательской приёмки. Отдельный merge L0 не планируется. Английский канон объявляется после закрытия всей локализации.

[Глоссарий 47 терминов](nomad360-terminology.md), [согласованные названия T1–T4](terminology-decisions.md), 1 758 явных семантических ключа и совместимость всех 1 292 прежних обращений. Числа, enum, идентификаторы и черновики остаются в прежней финансовой модели.

| Подэтап существующего плана | Материал / состояние |
| --- | --- |
| L0: все статические/динамические тексты, атрибуты, отчёты, ошибки | [Каталог и кандидаты](l0/README.md), машинная проверка актуальности, browser census |
| L1: словарь, проверка терминов, семантические ключи | Реализовано: реестр ключей, диагностика, глоссарий и согласованные T1–T4. Формула → профессиональный EN → согласованный RU → KK с английскими терминами |

| L6: языковая и числовая приёмка | Полная матрица, отсутствие пропусков, экономический смысл, сохранность данных и чисел |

Глоссарий `nomad360-terminology.md` сопоставляет формулы и профессиональные источники; статусы явно различают проверенное определение, границы сценария и ожидаемое согласование. Инвентарные hash-ID не являются семантическими ключами интерфейса. Финансовый источник истины — расчётный движок; ID, enum и пользовательские данные не переводятся. Случайный RU fallback не считается готовым переводом.

Глоссарий `nomad360-terminology.md` сопоставляет формулы и профессиональные источники; статусы явно различают проверенное определение, границы сценария и ожидаемое согласование. Инвентарные hash-ID не являются семантическими ключами интерфейса. Финансовый источник истины — расчётный движок; ID, enum и пользовательские данные не переводятся. Случайный RU fallback не считается готовым переводом.

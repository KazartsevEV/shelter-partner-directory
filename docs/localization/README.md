# Nomad360 · локализация L0–L6

Источник требований: [карта проекта](../nomad360-codex-task-map.md#задача-4-полная-локализация-ru--en--kk) и [утверждённые подзадачи L0–L6, Issue #101](https://github.com/KazartsevEV/shelter-partner-directory/issues/101). Эта папка хранит материалы существующего плана, не заменяет его новой очередью.

13 октября 2026: задача 3 принята, PR #134 объединён (`9e5a7f51`), публикация подтверждена SHA256-паритетом 25 assets. Начат **L0 — инвентаризация**. L1–L6 остаются впереди; английский канон объявляется после закрытия всей локализации.

| Подэтап существующего плана | Материал / состояние |
| --- | --- |
| L0: все статические/динамические тексты, атрибуты, отчёты, ошибки | [Каталог и кандидаты](l0/README.md), машинная проверка актуальности, browser census |
| L1: словарь, проверка терминов, семантические ключи | После L0; формула → профессиональный EN → согласованный RU → естественный KK с утверждёнными английскими терминами |
| L2: V1 товары | Производство / закупка / дропшиппинг, все условные поля и ошибки |
| L3: V1 услуги | Online/offline, self/hired/agent, simple/full, валидация |
| L4: V2 | Самостоятельный/связанный, общие ресурсы, MBA, предложения, налоги, кредит, Cash Flow, draft/restore |
| L5: отчёты/экспорт/подвал | PDF, Excel, скачиваемый HTML, атрибуты доступности и контакты; отдельная задача 6 не смешивается с локализацией |
| L6: языковая и числовая приёмка | Полная матрица, отсутствие пропусков, экономический смысл, сохранность данных и чисел |

Глоссарий `nomad360-terminology.md` создаётся в L1 после проверки реальных формул и авторитетных профессиональных источников. Инвентарные hash-ID не являются семантическими ключами интерфейса. Финансовый источник истины — расчётный движок; ID, enum и пользовательские данные не переводятся. Случайный RU fallback не считается готовым переводом.

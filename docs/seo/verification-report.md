## Ограничения среды и доказательств

Прямой Chrome TLS через средовой прокси вернул ERR_CERT_AUTHORITY_INVALID. Проверка выполнена без отключения TLS: Python urllib использовал штатный proxy/CA, HTTPS-ответы переданы Chromium без изменений; каждый first-party ресурс сверялся с baseline. Это **render опубликованных ответов**, не прямой браузерный сетевой замер производительности.

Tailwind CDN вернул 403; подменный CSS не внедрялся. Поэтому live-снимки фиксируют доступное в этой среде состояние и не являются полной визуальной приёмкой production. Виджет сторонних пожертвований намеренно заблокирован в аудите; его работа не заявляется проверенной. Платежи и письма не отправлялись. Существующие внешние ресурсы приложения не скрываются за заявлением «никаких внешних запросов».

Скрипт первоначально сообщал об ошибках init-script в сторонних фреймах. Он исправлен: предпочтение языка устанавливается только для origin приложения. Итоговый протокол не содержит этих ошибок. Это исправление тестового окружения, исходники сайта не менялись.

Прямые запросы Google дали JS/challenge shell без поисковых результатов. Публичный search-provider использован как дополнительное качественное исследование; он не гарантирует страну. Локальная популярность KK и естественность формулировок носителем не подтверждены. Никаких обходов, вымышленных объёмов или обещаний спроса.

CWV/Lighthouse и Search Console не измерялись. Результаты текущей фазы не равны полной функциональной матрице SEO-12/13, финальной локализации или факту индексации.

## Воспроизведение

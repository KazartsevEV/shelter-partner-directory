# BUG-09-SCREENSHOT — скриншот вместе с обращением об ошибке

**Статус 26.10: PREPARATION / private Draft [#501](https://github.com/KazartsevEV/lazysellerV2/pull/501), в общем handoff [#503](https://github.com/KazartsevEV/lazysellerV2/pull/503).** Actual widget + защищённый HTTP/codec/MIME реализованы и проверены локально (9 unit groups, 18 Chromium); actual Google и public release не включены, CI/приёмка отдельно. Изображение выбирается вручную, PNG/JPEG/WebP нормализуются в PNG без metadata; текст и файл входят в одно письмо. [#502](https://github.com/KazartsevEV/lazysellerV2/pull/502) готовит retention; реальное удаление Gmail/backups требует R5 прав и выбранного host producer. Текущий публичный `nomad360_bug_report.js` остаётся строго text-only/Formspree. Исходные требования ниже сохранены: R5 настоящее письмо, R6 согласованный cutover, не объявлять fixture приёмом реальных файлов.

## Пользовательский сценарий

1. В существующем плавающем виджете «Сообщить об ошибке» после описания и шагов появляется **необязательный** ввод «Приложите скриншот ошибки» с обычным выбором файла и возможностью удаления/замены, без автоматического доступа к экрану или сохранённым расчётам.
2. Помогающий текст: **«Скриншот поможет быстрее разобраться. Перед отправкой проверьте, что на изображении нет личных данных, расчётов или другой конфиденциальной информации.»**
3. Разрешить один файл PNG/JPEG/WebP; рекомендуемый максимум **5 MiB** (предварительный бюджет, подтвердить по реально выбранному provider/worker). Показывать имя, размер, локальный миниатюрный preview без загрузки до отправки; неподходящий тип/слишком большой размер — понятная локализованная ошибка. Клик/клавиатура/mobile/touch, отсутствие горизонтального переполнения от 320 px.
4. Текст ошибки обязателен; шаги, контактный email, скриншот **необязательны**. Ни регистрация, ни имя не требуются. Не присоединять URL с query, cookies, localStorage, бизнес-модели, PDF, Excel, паспортные документы или невидимое содержимое вкладки.
5. Явно показать, что **выбранный файл будет передан** стороннему обработчику/нашему закрытому сервису и доставлен разработчикам. Предусмотреть удаление ошибочно выбранного скрина перед отправкой. Не делать скриншот автоматически и не собирать изображение канваса калькулятора без выбора пользователя.
6. Успех отображается только после подтверждённого принятия **и текста, и выбранного файла**; если файл отклонён, не отправлять молча «текст без него» и не показывать успех. При timeout/429/413/unsupported type выводить разные локализованные ошибки и сохранять черновик/выбранный файл для явного повторного действия; не допускать автоматических дублирующих писем при неопределённом ответе.
7. RU/EN/KK тексты:
   - RU: «Приложите скриншот ошибки (необязательно)» / «Перед отправкой убедитесь, что на скриншоте нет личной или финансовой информации.»
   - EN: “Attach a screenshot of the error (optional)” / “Before sending, make sure the screenshot contains no personal or financial information.”
   - KK: «Қатенің скриншотын тіркеңіз (міндетті емес)» / «Жібермес бұрын скриншотта жеке немесе қаржылық ақпарат жоқ екеніне көз жеткізіңіз.» (проверить живой KK-редактурой).

## Реальное ограничение Formspree и выбранная архитектура

**Проверено 25.10.2026 по официальным правилам:**
- [Formspree file uploads](https://help.formspree.io/articles/building-your-form/file-uploads): загрузка файлов доступна на **Personal / Professional / Business**, не на Free. Нужны `multipart/form-data` и file input. Действующий endpoint `https://formspree.io/f/mwlvadod` использовался как **Free** и текстовый, работоспособность загрузки на нём **не подтверждена**.
- [Formspree plans](https://formspree.io/plans/): Formspree сохраняет файл у себя и отправляет в уведомлении **ссылку на файл, не бинарное MIME-вложение**. Нельзя обещать пользователю «скриншот прикреплён к письму» при простой миграции на платный Formspree.
- Не оформлять платную подписку и не включать upload в действующей форме без согласия владельца.

**Целевой контракт владельца:** одно обращение приводит к **одному письму** разработчикам (`nomad260393@gmail.com`), где текст ошибки и выбранное изображение находятся вместе; если возможно, именно PNG/JPEG/WebP во вложении письма, не только внешняя ссылка. Реализовать отдельным защищённым и изолированным **bug-report intake** + Gmail MIME adapter в целевом приватном backend R5. Партнёрский оператор выдачи ZIP имеет отдельные права/потоки; нельзя открывать его секреты или повторно использовать его регистрацию как баг-форму. Альтернативу с Formspree Personal+ и ссылкой на файл допустимо принять **только отдельным решением владельца**, поскольку это другой способ доставки.

Отправка по HTTPS после R4, серверная валидация MIME **и** file magic, максимальный размер/streaming до буферизации, безопасные имена, отсутствие SVG/HTML/исполняемых файлов, ограничение числа файлов, преобразование/удаление метаданных изображений по принятому контракту. Учесть, что проверка размера/типа в браузере не является защитой. Изоляция CAPTCHA/anti-spam от существующей партнёрской формы, rate limiting и бюджетов отправки согласно [SEC-01](../security/SEC-01.md); отдельный лимит вложений и квоты Gmail; безопасный digest и idempotency отчёта, а при неопределённом статусе отправки — проверка провайдера вместо автоматического повтора.

Политика: уточнить фактический processor, сроки хранения изображения/архивов, доступ к письму/файлу, удаление, конфиденциальность, явное уведомление о передаче. Не посылать скриншот в Google Sheet партнёров и не помещать в GitHub/CI-артефакты. Изменить текст privacy во всех трёх локалях: теперь по выбору пользователя передаётся также изображение; прежнее утверждение «передаётся только текст» станет неверным.

## Этапы и Definition of Done

- **R1 UI preview + согласование**: UX и тексты EN/RU/KK; выбор/замена/удаление файла; приватность, 320/360/390/430/768/desktop, keyboard/mobile; если transport не готов — не показывать работающий upload CTA, не обещать отправку изображения. Отдельный PR и пользовательская приёмка.
- **R4/R5 integration**: согласованный backend/provider и его доступность; защищённый upload, валидация, mail delivery, тестовое письмо на реальный mailbox с **фактическим** скриншотом. Проверить у получателя соответствие одной заявке и файлу; MIME вложение или явно согласованный link-only вариант.
- **Негативные тесты**: нет файла; valid PNG/JPEG/WebP; spoofed MIME; SVG/HTML; 0 B и > лимита; оборванный upload; сеть offline; timeout и неопределённый Gmail outcome; 429/quota/413; повторная отправка; файл удалён/заменён перед отправкой; не появилось доступа к калькулятору/черновикам.
- **Регрессия**: без изменений V1/V2/VAT/US Retail, PDF/Excel, автономного HTML, локализации и существующего Formspree text-only до отдельного выпуска.
- **Release**: только после конфиденциальностной и реальной email-приёмки; новый UI синхронно с включением готового endpoint, не заранее.

Следующий исполнитель начинает с реальных настройках Formspree и Gmail и не трактует существующую text-only доставку как подтверждение скриншотного сценария.

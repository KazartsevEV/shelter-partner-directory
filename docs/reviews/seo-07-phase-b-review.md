# SEO-07 · фаза B: EN и явный выбор языка

Пользователь принял остальные решения фазы A и попросил добавить справа в баннер логотип из хедера без нового файла изображения. Правка выполнена в двух макетах и общем шаблоне EN. Это **приёмка EN**, не закрытие всей задачи 7 и не разрешение на merge. Main и сайт этой веткой не публиковались.

## Что изменено

- Пять статических английских страниц: `en/`, `en/business-idea/`, `en/pricing/`, `en/cash-flow/`, `en/for-consultants/`. Полезный текст, один H1, уникальные title/description, self-canonical, Open Graph и обычные ссылки уже в исходном HTML. В страницах нет JS и финансового движка.
- Справа в баннере и в хедере используется **один существующий URL** `nomad360_wolf_open_circle.png`. Новый PNG, base64-копия или изменённая версия не создавались. На мобильном логотип находится справа от вводной строки, заголовок занимает всю ширину. Тест подтверждает один запрос изображения для двух элементов.
- Один генератор `scripts/seo/build.py` и декларативный `pages.json` задают origin/project path, метаданные и содержание. Повторная сборка детерминирована, дубли title/description/H1/URL запрещены. Никаких canonical вне project path.
- В приложении добавлены **только две HTML-строки**: self-canonical и подключение изолированного `nomad360_seo_language.js` после UI. Все остальные байты HTML защищены сравнением с принятой базой. Сам `nomad360_calculator_ui.js`, header, CSS, финансовые скрипты и их формулы неизменны.
- Адаптер языка: валидный `lang=en|ru|kk` выбирает язык после штатного UI boot; отсутствующий/неверный параметр сохраняет прежнюю логику stored/browser. Работает при недоступном localStorage. Ручная смена обновляет lang через replaceState, сохраняя demo/finance/прочие параметры/hash; не перезагружает приложение и не меняет финансовую модель.
- Существующий HTML-downloader автоматически включает новый модуль в переносимую версию. Генератор/статусы/повторная ссылка не менялись.

Содержимое source и DOM совпадает.

- 6 демо-кейсов RU/EN/KK × cash/credit: независимый оракул, ручной переключатель не меняет модель и financial localStorage; demo/finance/hash сохраняются.

- 8 проверок исправленных макетов и 4 снимка; source inventory обновлён детерминированно до 30 sources, без dictionary issues. Новых видимых строк в самом калькуляторе нет.

В браузерном финансовом harness сторонние ресурсы заблокированы; полная прежняя матрица с локальными utilities и PDF/Excel выполняется в существующем CI. Точное состояние каждого workflow проверять по текущему HEAD PR; ранние ошибки harness не выдаются за дефекты продукта и не скрываются.

## Границы source-защиты

В исторических marketing/type02 guards разрешены только точные две новые HTML-строки; после их удаления сравнивается весь исходный файл, включая все inline финансовые скрипты. Защита financial AST/арифметики не ослаблена. Семантический guard распознаёт новый UI URL-модуль как новый asset вне финансового baseline; он проверяется отдельными unit/browser тестами. Все прежние финансовые файлы продолжают сравниваться с исходными SHA. Словари UI и оффер не менялись. Census изменился из-за новых ссылочных строк и нового технического asset.

Первый локальный link-check ошибочно искал динамические footer anchors в HTML source; теперь проверяет разрешённые ID на запущенном приложении. Handoff smoke ожидал глобальное API до окончания навигации; ожидание исправлено на optional API. После этих исправлений весь новый browser protocol GREEN. Первые source-тесты также потребовали распознать новый UI asset, которого не было в старом финансовом SHA. Падения финансовой математики не обнаружены.

## Что остаётся

Эти страницы пока только в Draft ветке; реальные новые GitHub Pages URL до разрешённого merge остаются baseline 404. В `pages.json` `isPublished=false` обозначает этот факт, `readyForReview=true` — собранный кандидат. После приёмки EN предстоят RU → KK и их отдельная приёмка, взаимные hreflang, финальный sitemap и live-аудит после публикации. Сейчас только self-en; ссылок на отсутствующие переводы нет, x-default не выдуман.

Сохраняются ограничения исследования фазы A: нет подтверждённых Google-частотностей/географии/позиций, Search Console не подключён, KK носителем не проверен. Страницы не обещают спрос или лиды. Новый домен, CNAME, host-root robots, SHELTER, задача 7А и задачи 8–9 не затронуты.

Новый HTML составляет несколько КБ на страницу, CSS общий и JS отсутствует. Существующий оригинальный PNG весит 1 503 771 байт; он переиспользуется по требованию пользователя, не оптимизируется копией/перекодированием. Один запрос и кэширование не означают нулевую стоимость первой загрузки. Production CWV не измерены; лабораторные локальные результаты не выдаются за полевые данные.

**Следующее решение:** приёмка EN-содержания и вида с добавленным логотипом; затем RU. Это не запрос на merge.

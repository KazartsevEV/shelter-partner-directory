## Найденные зависимости до реализации/запуска

1. Старый Pages workflow публикует `path: '.'`. Новый deploy должен выпускать
   только проверенный каталог публичного сайта, а не приватное дерево исходников.
2. Код P3 находится в открытом Draft #243, не в main; перенос не означает merge.
   Все 5/5 CI jobs на `3314ec3` успешны, но реальный worker не авторизован.
3. Компания/сайт в форме необязательны, а текущий build config требует сайт/origin.
   Сценарий выдачи до размещения из #219 требует отдельной реализации/проверки.
4. Постоянный доверенный intake ещё не реализован; endpoint Formspree сам по себе
   не подтверждает происхождение произвольного JSON, переданного обработчику.
5. Текущий оператор требует одного POSIX-host с постоянным приватным диском.
   Serverless/multi-instance размещение без нового store/queue контракта не принято.
6. Смена origin требует переноса черновиков. Автоматического переноса localStorage
   нет; PDF/Excel не являются восстанавливаемым форматом черновика.
7. Домен/провайдер, сроки хранения и финальная политика данных ещё не выбраны.
   Не выдавать редакционный пакет за завершённую юридическую/KK-приёмку.

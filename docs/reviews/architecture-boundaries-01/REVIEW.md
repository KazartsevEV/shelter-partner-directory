# Архитектурный срез после PR #218

База: `b9802d0`. Ветка: `refactor/nomad360-boundaries-20261021`.

## Изменения

- Публичная выгрузка HTML отделена от хедера в `nomad360_delivery.js`.
  Интерфейс кнопки, имя файла и содержимое калькулятора сохранены.
- V1, самостоятельный V2 и связанный V2 используют единый адаптер браузерных
  черновиков. Ключи, сохранённые объекты и правила валидации старых V1/V2
  черновиков не изменены.
- Удалена невидимая строка валюты подвала и её последующее удаление из DOM.
- Устранена гонка теста восстановления V1 после `DOMContentLoaded`.
- Восстановлена загрузка обоих модулей в отдельном US Retail HTML; проверены
  русская и английская автономные выгрузки с исходными результатами.
- Исторические SEO/локализационные проверки сохраняют прежние ограничения:
  сначала сверяют точные хеши новых адаптеров, затем сравнивают с принятой
  базой. Визуальная TYPE-02 матрица теперь сверяется с актуальным `main`
  после PR #218, а не с предшествующей редизайну типографикой.
- Отдельный [документ границ](../../architecture/nomad360-boundaries.md)
  фиксирует оставшуюся связанность V1 и следующую очередь рефакторинга.

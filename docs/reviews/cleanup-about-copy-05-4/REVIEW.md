# C5-4 — единый владелец компоновки вступления About

База: принятый #254, merge `8c2f51dbfe3d497d5b6ad9dfdf5b787ea5813530`.
27 исторических правил opening/scene-copy сведены к 18 определениям, сохраняя
позиции RU/EN/KK, ширины и отступы. Тексты, шрифты, DOM, декорация C5-3, SVG,
палитра, финансовые модули и форматы черновиков не меняются.

## Граница и владельцы

Header создаёт локализованный DOM, About controller сохраняет существующие
обёртки/viewport variables. Scoped opening/scene-copy CSS владеет только
компоновкой вступления. Root, фотографии и маски сцены остаются у C5-1/C5-3.
Новых классов, ID или JS-адаптеров не добавлено.
SVG остаётся 147278 B, Git blob `f4722dcb407827fd6d7cbea35416e6eb434d60c0`.

Сохранены fallback-обёртки, интервалы 700/701/1000/1001 px и английские
планшетные/desktop-отступы. RU/EN/KK phone offsets остаются соответственно
`calc(50vw - 75px)`, `calc(44vw - 72px)`, `calc(44vw - 84px)`.
У неотрисованного opening `::before` остаётся итоговое `content:none`, а также
его прежние фоновые/масочные свойства: их не удаляли по отсутствию пикселей.

Точная квитанция — `tests/fixtures/cleanup-about-copy/removals.json`:
21 диапазон и SHA, плюс соседний `canonical.css`. Все остальные правила,
декларации и media-контексты сохранены. Отдельный oracle, независимый от
канонического CSS, учитывает специфичность, порядок, margin shorthand и media
при 300 комбинациях ширины/языка/обёрток, включая пустой/отсутствующий/неизвестный
lang. Отрицательные контроли обязаны выявить неверный отступ, потерю приоритета
и неправильную границу. Холодная браузерная матрица проверяется отдельно.

Неизменённый AST-анализатор сырых исходников: **190 → 185 групп;
вступление 5 → 0**. [Снятые группы и весь непроверенный остаток](ownership.json).
Остальные 185 не объявлены мёртвым кодом. Старый C5-3 ownership восстанавливает
свой исторический контракт и явно помечает нормализацию; его 190 не подменяют
актуальные 185. Вся задача C5 не закрыта.

Сайт: 320/360/390/430/699/700/701/768/999/1000/1001/1280/1440/1920/2560.
Автономный HTML: 320/700/701/1000/1001/1280/2560. Live resize:
390 → 1280 → 700 → 701 → 1000 → 1001 → 320. Сравниваются все computed properties
и геометрия всех About-узлов/отрисованных псевдоэлементов; у отсутствующих —
`content`. Нормализуются лишь локальные URL before/after. Дробный iframe
700,5/1000,5 px фиксирует фактические media-query результаты/округление Chromium;
это не выдаётся за исполнение дробной media-ветки. Её декларации проверяет oracle.

Две настоящие упаковки создаёт принятый builder из чистых tracked checkout.
Каждый non-About ресурс сохраняет размер/SHA; старых подложек нет, текущий SVG
встраивается один раз. CSS и HTML уменьшаются ровно на 1346 B, без новых
base64-разниц. Исторические source/size guards сохраняют оракулы через строго
проверенные мосты, считающие новую raw-разницу ровно один раз.

# C5-2 — единственный источник сцены «О проекте»

База: принятый и объединённый PR #252, `6b3bdbebea65ea8e26a8dfd983842d5eb96bb735`.
Изменение рабочего сайта — удаление двух перекрытых `background-image` из
`nomad360_about_banner.css`. Финальный SVG, его фотографический оригинал,
маски, размеры, цвета, шрифты, DOM, тексты и финансовые модули не меняются.
Это один компонент C5, а не закрытие всей очереди.

## Граница компонента

Единственный источник сцены — финальное безусловное правило
`#nomad360-information.nomad-information::before` с
`assets/nomad360-banners/about-moonlight-horizontal-only-3200x768.svg`.
Его Git blob остаётся `f4722dcb407827fd6d7cbea35416e6eb434d60c0` (147278 байт).

Удалены ссылки на `docs/approved-design/unified-banners/about-moon-scenery.webp`
и `assets/nomad360-banners/about-bozzhyra-approved.webp`. Оба файла сохранены
байт в байт для истории, ссылок и прежних выпусков; исторические комментарии
также сохранены. Финальное правило безусловно перекрывало обе декларации.
Это не резервные изображения на случай ошибки загрузки: CSS не возвращается
к предыдущему значению `background-image`, если итоговый ресурс недоступен.

DOM принадлежит header, декорация/viewport variables — About controller,
геометрия — компоненту C5-1, paint — существующей палитре. Эти владельцы и
внутренняя ширина контента не меняются.

Неизменённый AST-анализатор проверяет сырые исходники базы и текущей версии:
**217 → 216 конфликтующих групп; источник сцены 1 → 0**.
[Протокол владельцев и все 216 непроверенных групп](ownership.json).
Они не признаны мёртвым кодом и не разрешены к автоматическому удалению.
Исторический анализатор C5-1 отдельно восстанавливает свой контракт (217),
явно помечая нормализацию; он не подменяет текущий результат 216.

## Почему уменьшается автономный файл

Упаковщик встраивает все локальные CSS URL, в том числе перекрытые.
Две удалённые декларации исключают два ненужных base64-вложения.

| Ресурс | До | После | Разница |
| --- | ---: | ---: | ---: |
| About CSS | 29792 B | 29622 B | −170 B |
| Реальный автономный HTML | 13229878 B | 12980762 B | −249116 B |

Дополнительные 248946 байт — разница между исходными URL и их base64-формой.
Это проверяется настоящей сборкой двух чистых tracked checkout через принятый
упаковщик. В старом manifest есть оба изображения, в новом их нет. Каждый
остальной ресурс, кроме About CSS, совпадает по размеру и SHA.
В браузере эти два изображения и раньше не запрашивались. Снижение времени
загрузки сайта или улучшение production CWV здесь не заявляется.

## Проверки

- 93 теста границ, отрицательных сценариев, финансовых движков, черновиков и экспорта.
- 48 неизменных числовых налоговых эталонов; генератор палитры 281853 байта, L0,
  SEO, syntax и защищённый CSS проходят. Старые workflow и числовые эталоны сохранены.
- Основной сайт: RU/EN/KK × 320/360/390/430/699/700/701/768/999/1000/1001/1280/1440/1920/2560.
- Настоящий автономный HTML: RU/EN/KK × 320/700/701/1000/1001/1280/2560.
- 66 пар, 198 сравнений default/hover/focus всех computed properties и геометрии.
- 18 пар побайтово совпадающих PNG; 21 парная проверка live resize
  390 → 1280 → 700 → 701 → 1000 → 1001 → 320.
- 6 пар RU/EN/KK × 320/1280 при заблокированном финальном SVG: прежние картинки
  не запрашиваются, геометрия и стили совпадают, переполнения нет.
- Отрицательный контроль возвращает старый inset/max-width и обнаруживает потерю full width.

Здесь учитываются все стили отрисованных псевдоэлементов; отсутствующие
проверяются по `content`. Маски/цвета/геометрия не исключаются из сравнения.
Нормализуются только локальные URL-префиксы before/after.

Исторические C3/C4/C5-1 сравнения получили только строго проверенные мосты
метаданных. Фильтрация исключает лишь два известных размера/SHA; сторонние
ресурсы нельзя скрыть. Расширение base64 учитывается ровно один раз, отдельно
от уже посчитанного raw CSS. Неизвестные цвета, размеры, шрифты, URL или
изменённые исторические изображения отклоняются отрицательными тестами.

CI повторяет исторические матрицы C2/C3/C4/C5-1, включая 216 бизнес-сценариев,
восстановление моделей, повторную навигацию, 72 Excel/OOXML и 6 PDF-проекций.
Окончательные статусы на финальном HEAD публикуются в PR; локальный отчёт их
не заменяет. Живые анкеты, письма, реальные credentials и персональные данные
не использовались. Ручная сертификация Excel Desktop/драйверов печати не добавлена.

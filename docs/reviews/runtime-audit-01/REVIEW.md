# Runtime audit 01 — исходный контракт перед очисткой

База: `c4536e9edd60003efb0a9087ec60915d4c070bdd`, main после #244.
Это отдельный этап аудита, а не завершение всей архитектурной программы.
Калькулятор, его стили, финансовые формулы, сохранения и старые эталоны не изменены.
Все 73 исследованных файла сверены побайтово с базой до анализа и запуска браузера.

## Измерения и пределы

Первичная загрузка локальных ресурсов: 6,20–8,49 MB без HTTP-сжатия.
Готовность в профилируемой лабораторной среде: 3,39–4,48 s;
это не production Core Web Vitals и не обещание скорости реального телефона.
Загрузка одна на комбинацию: будущий замер производительности требует минимум
трёх парных повторов одного сценария в одинаковой среде.
Heap — V8 после GC, не полная память вкладки/GPU/картинок.

Внешняя сеть в сценариях блокируется; локальные utilities собраны закреплённым
Tailwind. Живые формы не отправляются, курсы/Google credentials не используются.
Coverage собран для основной матрицы; Help, US demo и автономная сборка имеют
DOM/метрики, но не расширяют набор точного JS/CSS coverage.
DOM-присутствие селектора не означает применения его media-правила.
Карта вызовов синтаксическая, без доказательства достижимости через все aliases.

Лабораторный скриншот не заменяет визуальную приёмку баннеров.
Существующий PDF-тест проверяет печатную DOM-проекцию и вызов print;
физический принтер и PDF-драйвер не проверяются.
13 исторических отказов online-import этим аудитом не закрыты.

# C5-5 — владельцы CSS семейств страниц

База: принятый #255, merge `930fc1bad7d34d9921bd543830e36caec2e2ef87`.
Код продукта, CSS, HTML-страницы, рисунки, шрифты, математика, черновики и
действующие workflow не меняются. Срез добавляет исполняемую карту загрузки
и проверки изоляции перед дальнейшей очисткой/переносом на hosting.

## Решение по группам

Общий AST-аудит собирает правила из разных документов. Одинаковый `.brand`
в legal и SEO не означает, что оба исходных файла загружаются на одну страницу.
Удалять такие определения или механически объединять их нельзя.

| Семейство | Страницы | Исходные CSS и граница |
| --- | ---: | --- |
| Calculator | 2 | Собственные stylesheet/inline styles; raw SEO/help/legal не подключены |
| EN SEO | 5 | `nomad360-seo.css`, статические шрифты, итоговая палитра |
| Help RU/EN/KK | 3 | SEO base → `nomad360-help.css` → fonts → palette |
| Legal RU/EN/KK | 3 | `nomad360-legal.css` → fonts → palette |

Маркеры палитры `.intro-copy` и `.legal-article` проверяются и по HTML, и после
реального запуска. Граф учитывает локальные imports; чужой origin, повторный
stylesheet, чужое семейство, неверный порядок help, отсутствие палитры и новые
HTML в объявленных корнях без записи в карте отклоняются отрицательными тестами.

**Сырой AST остаётся 185 → 185.** Из них **19 проверены и сохранены**, а
**166 ещё не проверены**. Ранее сняты 39 групп. Это не удаление 19 конфликтов.
[Исполняемая карта](../../architecture/nomad360-style-owners.json) ·
[19 решений и фактические подключения](ownership.json).

Сохраняются отдельные card/brand/intro/link-стили семейств, намеренная
последовательность help focus и инверсия выбранного языка `.help-lang span`.
Речь о взаимоотношениях исходных объявлений; итоговый focus задаёт общая
палитра: **3px solid #173B58, outline-offset 2px** во всех проверенных
статических семействах. Выбранный язык справки — белый на #173B58.
Две смешанные группы `body color/background`, содержащие несколько объявлений
в калькуляторе, намеренно оставлены для отдельного компонентного разбора.

Список выводится из свежего запуска неизменённого AST-анализатора, не только
из прежнего JSON. Все 19 групп сверяются с независимой frozen-квитанцией.
Никаких runtime-адаптеров и исключений в старых source guards не добавлено.

## Проверки и фактический результат

- 108 unit/source/financial/draft/export тестов; 48 замороженных числовых налоговых эталонов.
- Palette/L0/SEO/syntax проходят; генерируемая палитра остаётся 281853 B.
- 120 пар before/after при 320/360/390/430/768/1280 px: 13 текущих страниц и
  реальный standalone; оба калькулятора/standalone проверяются в RU/EN/KK.
- Порядок `document.styleSheets` равен графу, runtime-маркеры палитры соответствуют семейству.
- Все выбранные computed styles, геометрия, тексты и число DOM-узлов совпадают;
  горизонтального переполнения нет. Цвет выбранного языка справки подтверждён.
- 22 пары PNG секции intro совпадают побайтово; 102 пары keyboard-focus probes.
- Реальные HTML-упаковки совпадают **целиком побайтово**: 12976248 B;
  каждый из 63 ресурсов имеет прежний размер/SHA. Различается только revision
  во внешнем manifest, не в HTML. Снижение payload/CWV здесь не заявляется.

Focus probes — явно синтетические anchor/summary, добавленные только тестом
после основного снимка состояния. Это не новые элементы продукта и не
утверждение, что каждый focus-selector имеет видимый DOM на каждой странице.
Снимки сделаны после загрузки шрифтов и decode видимых eager-изображений.
Тестовые запросы обслуживаются точными файлами двух checkout, без реальных POST.

## Ограничения и приёмка

Архивные/FILLED HTML, SHELTER index, mockups, будущие plugin/config layout
не объявляются мёртвыми и не удаляются. Это отдельная C7-очередь. Карта
описывает текущие входные страницы, не все возможные сторонние вставки.
При переносе hosting origin/prefix/входные страницы обновляются явно вместе
с тестами; текущее разрешение не включает DNS, приватизацию или запуск выдачи.

# Задача 4 · Nomad360 RU / EN / KK · L0–L6

14 октября 2026. Один [Draft PR #135](https://github.com/KazartsevEV/shelter-partner-directory/pull/135), база принятого Excel `9e5a7f51b22ff9240cb9a520203182e0b448d623`. PR #134 объединён и опубликован; задача 4 в main не объединена. Следующий шоппер, TYPE-02, маркетинг, SEO, справка и баг-форма не начинались.

## Результат реализации

- L0: консервативный AST/HTML-реестр всех 29 локальных источников, включая условные формы, атрибуты, шаблоны, ошибки и экспорт. Первоначальные доказательства L0 на `1b405fae` сохранены отдельно; текущий реестр обновляется с кодом и проверяется на актуальность.
- L1: 1 758 явных семантических ключа. 1 292 прежних RU-обращения остаются alias, что сохраняет существующие вызовы и восстановление. Новые строки не получают ID из текста во время выполнения. Общий реестр обслуживает 11 пространств компонентов; локальные словари — проверяемые снимки совместимости для загрузки отдельных модулей. Отсутствующий ключ показывает `⟦key:language⟧` и попадает в диагностику; неизвестная legacy-строка также диагностируется.
- Проверены [47 терминов и формул](../localization/nomad360-terminology.md) по IFRS/IAS, AMA, Google Ads, профессиональному бухгалтерскому словарю, CFPB, ICC и OECD. Определения отделены от границ сценарной модели. «Живые деньги» не объявляются Free Cash Flow, LTV Factor не объявляется классическим LTV, Margin не заменяется Markup.
- Пользователь отдельно согласовал [T1–T4](../localization/terminology-decisions.md): стоимость привлечения и обслуживания клиента; выручка после эквайринга; ROAS после эквайринга; прибыль базового месяца до процентов по кредиту. Числа остались прежними, состав затрат и ограничения раскрыты в пояснениях.
- L2/L3: материалы, производство, закупка, dropshipping, online/offline и self/hired/agent, условные поля, расчётные подписи, ошибки и Cash Flow. Казахские предложения сохраняют профессиональные EN-термины; нет отдельного противоречащего EN словаря.
- L4: самостоятельный/связанный V2, ресурсы, распределение, MBA, FX/payment UI и совместимость старых сохранений. Полные словари компонентов включают массивы и вложенные разделы.
- L5: локализованы PDF V1 и V2, листы и примечания Excel, UI сохранения/восстановления, заголовок/атрибуты. Обычное пожелание в подвале переведено; маркетинговая переработка задачи 6 не выполнялась. Юридические реквизиты, URL и имена не переводятся.
- Параметризованные подписи V1 используют ключ + исходные аргументы вместо догадок по названию. Пользовательские SKU/названия/ресурсы защищены, включая «Выручка» и строки с кавычками, `»`, `<b>`, `{name}` и `$&`.
- Дополнительная проверка открытых сохранённых карточек V1 нашла переполнение edit/delete на 320 px. Scoped CSS переносит группу действий под названием без изменения размеров шрифта/чисел. Тест подставляет настоящий CSS базы `9e5a7f51`, подтверждает RED, затем возвращает текущий CSS и подтверждает GREEN.

## Доказательства и границы

[Исходный реестр](../localization/l0/README.md), [глоссарий](../localization/nomad360-terminology.md), [согласованные термины](../localization/terminology-decisions.md). CI публикует исходный census, отдельный протокол пользовательских названий/PDF и полный набор снимков. Постоянные компактные контрольные PNG/протоколы будут приложены после окончательного CI на точном HEAD.

Source candidates — консервативный реестр, включая ID, enum, URL, машинные строки и фрагменты шаблонов. Его количество не объявляется количеством отсутствующих переводов. Browser GREEN охватывает перечисленные сценарии; пользовательская языковая/визуальная приёмка остаётся впереди. Desktop Excel не проверялся вручную в этой задаче; фактическое XLSX чтение выполняет существующий Excel CI. Финансовые формулы, налоги, кредит, Cash Flow и формат черновиков не менялись.

**На приёмке задачи 4.** PR #135 остаётся Draft. Merge требует отдельного разрешения. EN становится терминологическим каноном после закрытия L0–L6 пользователем; финансовым источником истины остаётся расчётный движок.

# PR #133 — материалы V1, перенос KK на 320 px

Доработка по ревью `5507474649`, 13 октября 2026. Проверенная реализация и тесты: `fccdcc0bbd06a89c7147b62e379e0ec5289ab79f`. Статус: визуальная доработка предъявлена на окончательную пользовательскую приёмку; merge не выполнялся.

## Изменение

Только scoped CSS в `nomad360_payments.css`, внутри `#material-cost-entry-panel`: переключатели known/calculate размещены в одну колонку до 768 px; две колонки остаются на более широком экране. На мобильных уменьшены горизонтальные отступы контейнера и кнопок конвертера, чтобы длинное казахское слово помещалось при прежнем размере шрифта. Подписи переключателей и конвертера переносятся по границам слов. HTML, data-атрибуты, обработчики, расчёты, валюты и форматы черновиков не изменены.

## Проверка

Новый `tests/currency_converter_layout_browser.test.cjs` использует настоящее приложение и CSS из исходного HEAD `26d8d01f` для воспроизведения старого дефекта. Проверяет размещение каждого слова через DOM Range, а не только внешние размеры кнопки. Требует воспроизводимого разрыва «Анықтамалық» на исходной версии и отсутствия разрывов/выхода слов за кнопку после правки.

Матрица: RU/EN/KK × 320/360/390/430/768/1280 px = 18 случаев; геометрия, touch target, размер шрифта, работа known/calculate, исходные 1000 CNY и нормализованные 2000 USD. Фикстура ручного курса 2 не является рыночным курсом. Снимки всей секции материалов и отдельной панели конвертера, включая до/после 320 KK, и численный протокол сохраняются в CI-артефакте `currency-converter-browser/layout/`.

Локально JS syntax, `git diff --check` и 22 контрактные/unit/parity проверки прошли; локальный Chromium здесь не запускался. Проверки подготовки формы используют штатную отправку клавишей Enter, переключатели known/calculate проверяются реальными кликами. Ранние попытки теста останавливались на нестабильной геометрии стартовой кнопки; эта подготовительная проблема устранена без изменения приложения. Live-проверки остаются строгими: один промежуточный запуск получил таймауты Frankfurter и завершился RED; в следующем завершённом запуске все 16 запросов успешны. Поведение и таймаут конвертера не изменены.

## Границы визуального осмотра

До правки просмотрены 144 исходных снимка панелей; это не полный аудит страниц. Длинное значение источника в input может быть видимо частично, полное применённое значение выводится ниже. Нативный date input следует локали браузера; применённая дата показывается в ISO-формате. Эти свойства правкой не изменяются. Historical visual workflow остаётся отдельным пропущенным job; его нельзя считать пройденным. 13 исторических ошибок онлайн-импорта остаются отдельным долгом.

PR остаётся Draft. Excel и следующие задачи не начаты; после повторных проверок требуется окончательная приёмка владельца и отдельное разрешение на merge.

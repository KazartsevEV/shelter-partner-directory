## Реализовано

- Прежний B2B-список из пяти пунктов заменён отдельным слоганом и **ровно тремя** HTML-карточками с номерами 1–3 и декоративными inline SVG-иконками.
- Исходный логотип волка, белая круглая маска, тёмно-синий `#16375a`, оранжевый `#ed8e63`, существующий Inter; новые шрифты/логотипы не загружаются.
- Локализация всех текстов через `Nomad360LocaleCore` на RU/EN/KK. Последняя RU-редакция пункта 2 заканчивается «**в онлайн-чате**». Курсивом выделен только согласованный фрагмент третьего пункта.
- Desktop: три карточки по горизонтали, mobile: адаптивные вертикальные ряды; текст остаётся HTML, не накладывается на растровый баннер.
- Прежняя B2B-кнопка раскрытия таблицы, скачивание полного HTML и повторная ссылка, заказ по email, 14-дневный счётчик GitHub, лицензия и реквизиты не переписаны.
- Выявленный браузерным регрессионным тестом дефект `Nomad360UI.setLanguage()`: `buildShell()` раньше заменял весь footer при смене языка, закрывая таблицу. Теперь сохраняется существующий footer-узел; его локализованное содержимое обновляет штатный `renderFooter()`.

## Проверки и источники доказательств

- Выполнен непосредственный запуск `Nomad360LocaleCore` и `footerMarkup()` на RU/EN/KK: **3 карточки**, номера **1–2–3**, **3 SVG**, **один `<em>`**, слоган, кнопка и сравнение — на всех языках; проверены согласованные формулировки.
- Дополнен существующий Chromium-сценарий `tests/nomad360_marketing_browser.cjs`: тексты, геометрия карточек, логотип, оформление, раскрытие сравнения и **переключение языка с открытой таблицей**. Проверяемые ширины: **320 / 360 / 390 / 430 / 768 / 1280 / 1440** на RU/EN/KK.
- Обновлены узко scoped тесты `tests/nomad360_marketing_scope.test.cjs`, `tests/return_7a_scope.test.cjs` и исходные SEO-byte-guards. Остальные переводы и финансовые исходники защищены прежними эталонами.
- Заново сформирован детерминированный инвентарь `docs/localization/l0` после окончательной правки UI, без ослабления `inventory.cjs --check`.
- В предыдущем цикле CI были подтверждены зелёные проверки SEO-07, RET-07A, L0 и лицензии, но **Chromium обнаружил закрытие сравнения при смене языка**. Дефект исправлен. Актуальный итог последнего CI необходимо смотреть на странице [PR #159 — Checks](https://github.com/KazartsevEV/shelter-partner-directory/pull/159/checks); не считать прежние прогоны доказательством GREEN для нового SHA.

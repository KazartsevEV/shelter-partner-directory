# C5-10 — проверка намеренных конфликтов палитры и CSS fallback

База: принятый `main` после #258 (`050bce7`). Это **аудит без изменения runtime**. `ledger.json` содержит 27 проверенных записей с полным `selector/context/property/important`, точными исходными объявлениями и причиной сохранения.

- **26** групп из генерируемого `nomad360_palette.css` имеют `!important`, именованный `@layer nomad360-palette` и конкурирующие значения поверхностей/текстовых `--p10-*`. Победа позднего правила учитывается генератором и утверждённым дизайном; его удаление напрямую из generated output запрещено.
- **1** группа `width:100vw;width:100cqw` в `nomad360_consulting_banner.css` намеренно оставляет fallback для браузеров без container-query units. Правило корректно и не подлежит автоматическому dedupe.

Данные не заменяют необходимость классифицировать все остальные группы.

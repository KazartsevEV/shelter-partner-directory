# PR #218 — векторный баннер «О проекте»

## Что изменено

- Утверждённый кадр `about-bozzhyra-desktop-extended-20261019.webp` преобразован в 4685 SVG-контуров. Новая подложка не содержит `<image>` или встроенного WebP. Сцена воспроизводимо создаётся `scripts/about/build_vector_scene.py` с `vtracer==0.6.11` и ImageMagick.
- На широком экране центральный пейзаж сохранён в исходной композиции; справа продолжаются только крайние скалы, чтобы не появлялась вторая луна. Край плавно переходит в утверждённый `#173B58`.
- На телефоне полностью видна центральная композиция 1536:768. Заголовок расположен на тёмном небе, подзаголовок — на синем переходе; крупный пустой промежуток перед карточками убран.
- Автономный HTML теперь встраивает локальные фоновые изображения и шрифты из CSS. URL большого SVG записан в CSS один раз: размер экспортированного HTML снизился с 24,35 до 17,97 МБ после устранения трёхкратного встраивания.

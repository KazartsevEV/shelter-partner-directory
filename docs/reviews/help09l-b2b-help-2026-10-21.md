Date: 2026-10-21. Tracking: [HELP-09 #221](https://github.com/KazartsevEV/shelter-partner-directory/issues/221), partner roadmap [#219](https://github.com/KazartsevEV/shelter-partner-directory/issues/219).

## Editorial decision: write release documentation in present tense

Nomad360 is a project under development; no partner installation or official individual distribution has occurred. Help is authored as **the product's intended release documentation in present tense**. It does not use temporary phrasing such as "will be available after launch", which would force another editorial rewrite. This content describes the target partner lifecycle in #219, not the live state of the current prototype. The release gate remains a separate implementation and acceptance task.

The existing prototype's `nomad360_header.js` still exposes immediate download of the free HTML. This change **does not** replace or remove that UI action, the present licence, or the current generator. At partner-distribution acceptance (stage 5 of #219), **H11/H12/H14, public UI and licence must be verified and switched together** to the individual issuance process for the new release.

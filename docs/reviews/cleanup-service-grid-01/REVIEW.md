## Изменение

Из `nomad360_design_system.css` удалён ранний трёхстрочный дубль
`body #full-service-screen .nd-full-service-inputs`. Более позднее такое же
правило и оба мобильных переопределения остались побайтно прежними.
В компоненте две сетки: общие параметры и условные параметры кредита.
В итоговом каскаде обе получают те же значения.

Промежуточное мобильное правило расположено между дублями, поэтому удалялся
только ранний блок. В действующих исходниках не обнаружены обращения к
`cssRules`, `styleSheets`, `insertRule` или `deleteRule`; это статическое наблюдение,
а не общее доказательство недостижимости всех возможных CSSOM-действий.

Генератор палитры запущен в `--check`: результат полностью прежний.
В удалённом блоке нет цветовых деклараций, поэтому и исходник генератора, и
`nomad360_palette.css` сохраняются без изменений. Цвета, шрифты, баннеры, формы,
математика, локализация и данные пользователя не менялись.

## Защита исторических контрактов

Новый scope-helper принимает только исходный CSS или его точную версию без
этих трёх строк. Любая другая правка отклоняется, включая добавленный комментарий,
изменённое значение и удаление оставшегося правила. Старые source guards получают
обратно ровно исходные байты, после чего продолжают прежние проверки.
SEO allowlist допускает файл только вместе с таким строгим контролем; финансовые
ожидания, фикстуры и старые браузерные тесты не менялись.

## Размер и производительность

| CSS | До | После |
| --- | ---: | ---: |
| Исходный файл, байт | 90336 | 90213 |
| Gzip level 9, байт | 17705 | 17692 |
| Brotli default, байт | 14871 | 14869 |

Цель C1 — убрать подтверждённый дубль, не заявлять заметное ускорение сайта
от экономии 123 байт. Автономный HTML: 16 224 965 → 16 224 842 байта. Остальные ресурсы сборки
совпадают по размерам и SHA-256.

Три парных повтора на каждую ширину, порядок before/after чередуется:

| Ширина | Медиана ready до → после, ms | Медиана V8 heap до → после, байт | Обработчики |
| --- | ---: | ---: | ---: |
| 390 | 1049,18 → 1086,56 | 5 468 144 → 5 470 852 | 277 → 277 |
| 1280 | 1052,19 → 1050,88 | 5 529 100 → 5 527 080 | 277 → 277 |

Мобильная медиана времени на 37,38 ms выше; desktop практически прежний.
Три повтора не позволяют приписать такую вариацию удалению CSS: измеряются
весь старт страницы, загрузка и компиляция ресурсов, открытие формы и шрифты.
Диапазоны mobile samples перекрываются: 990–1136 ms до и 978–1121 ms после.
Распределения отдельных samples приведены в полном протоколе; изменений JS,
добавленных ресурсов или обработчиков нет. Ускорение этим изменением не заявлено.
V8 heap отличается на несколько KB и не представляет всю память вкладки. Это
лабораторные наблюдения при блокированной внешней сети, не production Core Web Vitals.

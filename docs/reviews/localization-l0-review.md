## Находки и дальнейший разбор

1. **Ошибки чеков:** «Чек 1: нужен непустой список items.» и «Чек R1: неверная позиция 2.» остаются русскими в EN/KK. Проверено вызовом действующего переводчика; regex `nomad360_locale_core.js:1372–1373` содержит двойное экранирование. Владельцы: locale core / MBA diagnostics, L1/L4.
2. **Самостоятельный V2:** `. Денежные доли суммарно 100%.` в `portfolio_v2_ui.js:272` — несопоставленный фрагмент составной подписи. Владелец: standalone UI, L4.
3. **Полная услуга:** `Некорректное значение: Мощность` — русское сообщение в `full-service-message` на EN/KK. Владельцы: full-service engine diagnostic / UI, L3/L4.
4. **V1 после расчёта:** старый шоппер выявляет дополнительные несопоставленные подписи себестоимости, налогов, кредитов и Cash Flow. Их конкретные контексты сохраняются в census. Составные строки с названием товара требуют перевода оболочки с сохранением исходного названия, а не перевода SKU.
5. **Диагностика сама требует корректировки:** старый `auditVisibleGaps` принимает некоторые естественные KK-строки за русские по общему кириллическому диапазону. Census хранит оригинальный сигнал и отдельно точные совпадения с KK-словарём. 60 локальных состояний с оставшимися сигналами требуют разбора; это не 60 доказанных ошибок перевода.
6. EN `partner` / KK «серіктес» в переменной диагностике при русском «принципал» требуют согласования с действующей агентской терминологией. Проверка Margin/Markup, Available Cash, LTV Factor и всех групп из карты выполняется в L1 по формуле и профессиональным источникам.

## Состав изменения и ограничения

Добавлены development-only extractor, фиксированные зависимости/lockfile, автоматический контроль актуальности, тесты, исходный каталог и собственный CI. Карта меняется только в статусах/первом действии после приёмки Excel. **Ни один файл runtime JS/HTML/CSS, финансовый движок, сохранённый формат или значение модели не изменён.** Документы не подключаются в калькулятор и не входят в скачиваемый HTML.

External Tailwind/widget/iframe и сторонний XLSX-код исключены из собственного словаря явно; `index.html` — партнёрский каталог, вне области Nomad360. Пользовательские данные браузера в реестр не выгружаются: source census читает файлы проекта, browser census работает с тестовыми сценариями. Отчёт не является профессиональной/лингвистической приёмкой EN/KK. Исторические 13 online-import падений не исправлялись и не входят в 20 unit-проверок этого этапа.

L0 предъявляется отдельно по последовательному режиму работ. GREEN подтверждает работу инвентаризации, не полноту перевода. L1–L6 остаются открыты, EN не объявлен каноном; следующий подэтап — проверка терминов и устройство словаря по существующей карте. Merge текущего PR требует отдельного разрешения.

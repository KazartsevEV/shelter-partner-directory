# C5-3 — единый владелец геометрии и масок декорации About

База: принятый #253, merge `25572021ae685ed8fc85da689f528957b0c6986f`.
Компонент — scoped `#nomad360-information.nomad-information::before` и `::after`.
19 накопившихся правил сведены к 10 базовым/responsive-правилам. Значения,
которые реально применялись, сохранены; остальные селекторы и их объявления
не меняются. Это один срез C5, а не завершение всей очистки.

## Владельцы и контракт

| Ответственность | Сохранённый владелец |
| --- | --- |
| DOM, IDs, локализованный текст | `nomad360_header.js` |
| Viewport-переменные и обслуживание декорации | `nomad360_about_banner.js` |
| Fullbleed root, внешние отступы и clipping | Scoped компонент C5-1 |
| Исходное изображение | Утверждённый SVG C5-2, без перерисовки |
| Геометрия, фоновые масштабы, маски и scrim псевдоэлементов | Канонический scoped CSS C5-3 |
| Цветовые токены и внутренние 1138px wrappers | Существующие слои палитры/контента |

SVG `about-moonlight-horizontal-only-3200x768.svg` остаётся 147278 байт,
Git blob `f4722dcb407827fd6d7cbea35416e6eb434d60c0`. Фотографический оригинал,
качество, состав изображения, цвета, шрифты, тексты и математические модули
не меняются. Старые изображения остаются в репозитории и не возвращаются в
автономную сборку. URL актуального SVG присутствует ровно один раз.

Удаляемые диапазоны зафиксированы независимо в
`tests/fixtures/cleanup-scene-layout/removals.json` (17 диапазонов и SHA).
Канонические правила — в соседнем `canonical.css`. Негативные тесты отклоняют
изменённые маски, высоты/ширины, шрифты, цвета, URL, лишние байты и неверные SHA.

Сохранены исходные media-границы. Ветка `min-width:701px` покрывает и дробные
ширины до desktop; размер tablet-фона отдельно ограничен `max-width:1000px`.
На 1000,5 px desktop ещё не включается, а часть non-mobile стилей уже работает.
На 700,5 px mobile выключен, non-mobile ещё не включён. Нельзя незаметно
заменить это тремя строго целочисленными интервалами: тогда iframe меняет вид.
Браузерный тест фиксирует реальные media-query результаты и округление
внутри iframe с дробной CSS-шириной. Chromium округляет media-viewport;
сравнение такого iframe не выдаётся за прохождение дробной media-ветки.
Отдельный AST-тест сравнивает итоговые декларации обоих псевдоэлементов
на 700/700,5/701/1000/1000,5/1001 px, сохраняя семантику исходных интервалов.

Неизменённый AST-анализатор работает с сырыми исходниками:
**216 → 190 групп; декорация 26 → 0**.
[Владельцы, снятые группы и 190 непроверенных групп](ownership.json).
Статический поиск по runtime-модулям и обоим HTML не выявил обращений
к CSSOM `cssRules/styleSheets/insertRule/deleteRule/addRule`. Контроллер
меняет viewport-переменные, а не индексы CSS-правил; live resize проверяется отдельно.
Остаток не объявлен мёртвым кодом. Исторический C5-2 ownership отдельно
нормализует более позднюю консолидацию и помечает это; его 216 не подменяют
текущий результат 190.

Основной сайт: 320/360/390/430/699/700/701/768/999/1000/1001/1280/1440/1920/2560.
Автономный HTML: 320/700/701/1000/1001/1280/2560. Live resize:
390 → 1280 → 700 → 701 → 1000 → 1001 → 320. Сравниваются все computed properties
и геометрия всех About-узлов и отрисованных псевдоэлементов; отсутствующие
псевдоэлементы проверяются по `content`. Маски, цвета, SVG и геометрия не
исключаются из сравнения. Нормализуются только локальные URL before/after.

Обе упаковки собраны принятым builder из чистых tracked checkout. Каждый
non-About ресурс имеет прежний размер/SHA; старых подложек нет с обеих сторон.
HTML, как и CSS, уменьшается на 3168 байт. В этот раз нет дополнительных
base64-разниц — текущий ресурс по-прежнему встраивается ровно один раз.

[Полный протокол](protocol.json) · [Сводка](summary.json) · [Браузер](browser.log)
· [Unit](unit.log) · [Налоговые эталоны](vat.log) · [Ownership](ownership.log).

Старые workflow и числовые эталоны не изменяются. Тестовые адаптеры распознают
только точные новые CSS-байты/SHA и восстанавливают прежние источники для
исторических guards. Добавочная raw-разница учитывается ровно один раз,
не повторяя base64-экономию C5-2. C5-2 получил лишь узкие мосты размера и
исторического ownership. Отдельный CI job повторяет исходные C4-проверки:
216 бизнес-сравнений, полные модели/восстановление, 18 repeated-пар,
72 настоящие Excel-выгрузки с независимым OOXML-чтением и 6 PDF-проекций.
Статусы финального HEAD публикуются в PR и не заменяются локальным отчётом.

# TYPE-02 B — Inter во всём интерфейсе

База: `main b1cc9b50ae48c3c8f392e4342fb5243c7575bd8e`, включая принятые PR #139 и #141. Работа продолжена в одном Draft PR #142 после выбора пользователем Inter. Казахстан / Қазақстан / Kazakhstan и пользовательские названия оставлены без изменений по последнему указанию пользователя.

## Изменение

Inter подключён централизованно: оригинальные четыре WOFF2-подмножества, OFL, `font-display:swap`, ось 400–700. Байты встроены в экранный CSS, поэтому существующий экспорт HTML сохраняет гарнитуру без дополнительного сервера и внешнего сервиса шрифтов. Проверка SHA-256 сверяет их с оригинальным манифестом этапа A. Финансовые данные в подключении шрифта не участвуют.

Обычный текст 400, метки 500, заголовки и действия 600, денежные показатели 700; числа используют tabular nums. Поля не меньше 16 px, подсказки не меньше 14 px. Крупный hero сохраняет свою композицию. Контекстные роли заменяют глобальные переопределения `text-xs/text-sm/font-semibold` и всех заголовков. Отдельно приведены к шкале агентские payer-поля, конвертер, полная услуга, таблицы, About/Contacts и экспортные действия. На мобильном экране таблицы V2 прокручиваются внутри прежнего контейнера, денежные значения не делятся внутри числа.

HTML изменён только внутри CSS. Единственное изменение рабочего JavaScript — семантический класс `nd-type-note` на существующем примечании связанного V2. Guard сравнивает весь остальной HTML/JS, ID, тексты, enum, лицензию и финансовые модули побайтово с базой. Прежняя узкая поправка visitor-counter guard сохраняется; финансовый AST остаётся на принятой базе Excel `9e5a7f51`.

## Проверки и доказательства

Первый локальный полный прогон: 72 пары / 144 состояния до/после (RU/EN/KK × шесть ширин × четыре маршрута × два состояния), 396 оригинальных PNG, финансовый паритет. Дополнительно проверены восстановление, видимая ошибка сертификата, системный fallback и эквивалент 200% reflow. После этого исправлены мелкие подписи агентских сценариев, конвертера и мобильного monthly report; финальный CI повторяет матрицу на итоговом коде.

Независимо: 225 unit/финансовых регрессий, 8 source/font/semantic guards; полная языковая матрица 486 сценариев без числовых изменений и переполнений; расширенный контроль размеров и весов всех 27 бизнес-сценариев на 320 px прошёл 81 языковую проверку. Итоговый TYPE-02 CI дополнительно запускает этот контроль на всех шести ширинах. Это разные наборы с пересечениями, их суммы не выдаются за число уникальных сценариев.

Печать: три языка, реальное создание PDF и сравнение текста, размеров, высот, весов и межстрочных интервалов каждого элемента с базой. Самостоятельная печатная гарнитура Arial сохранена. Единственное намеренное отличие — H2 отчёта больше не наследует экранный IBM Plex Sans через старое глобальное правило, а получает Arial своего печатного контейнера; размер, вес, строки и высота проверяются без исключений. Guard допускает только это явно названное различие font-family. Денежные итоги и размер листа не меняются.

Скачиваемый HTML: три настоящих файла, четыре встроенных шрифтовых подмножества, отключённая внешняя сеть. CDP подтвердил реальный custom Inter для всех казахских букв; в экранном тесте отдельно проверяются веса 400/500/600/700. Внешние Tailwind/widget-ресурсы сохраняют прежний контракт; для воспроизводимого теста utilities добавляются локально.

Промежуточный CI выявил устаревшие ожидания IBM Plex Sans и весов/размеров до TYPE-02. Они заменены точными значениями принятой шкалы; финансовые, геометрические и навигационные assertions сохранены. Исторический converter RED воспроизводится на полном принятом pre-TYPE-02 main `b1cc9b50` с исходным payments CSS `26d8d01f`, а не на смеси старого компонента и нового Inter. Он подтвердил прежний разрыв слова; последующая проверка обнаружила реальные 14px material-кнопки, исправленные до 16px. Стиль note теперь явно исключает метки полей, для которых проверяются 16px/500. Один timeout caption-click полной услуги прошёл при следующем прогоне; принудительные клики и отключение проверок не добавлялись.

**CI точной реализации `0b22fe2`: 12/12 рабочих workflows, 13/13 рабочих jobs GREEN.** Один historical V2 visual workflow skipped по прежней конфигурации. [TYPE-02 CI](https://github.com/KazartsevEV/shelter-partner-directory/actions/runs/38621245253) содержит 225 + 3 unit/source/font tests, 72 пары / 144 состояния, 396 PNG, 12 extras, четыре реальных веса Inter и 486 языковых проверок всех бизнес-сценариев. Отдельный localization CI также подтвердил 486 + 54; платежи, конвертер, живые пары Frankfurter, Excel, shopper и общий numeric audit GREEN. Наборы пересекаются и не суммируются как уникальные тесты.

Из четырёх оригинальных CI ZIP опубликованы [144 контрольных PNG до/после](type02-typography/comparison.md), [полный экранный протокол](type02-typography/protocol.json), [PDF/HTML-протокол](type02-typography/exports-protocol.json) и [provenance с digest архивов, source hashes и SHA-256 оригиналов](type02-typography/ci-implementation.json). Все ZIP сверены с digest GitHub. [Интерактивный viewer](type02-typography/comparison.html) позволяет выбрать язык, ширину и экран; его нужно открыть как HTML. Снимки сохраняются исходными байтами, без редактирования.

Контраст проверенных hero/сертификатов — минимум 5,005:1; это не заявление о новом сплошном контрастном аудите всего сайта. Вручную осмотрены контрольные KK 320 / EN 390 сертификаты, RU 1280 валюта и KK 390 About, дополнительно прототипные hero и результаты. Осмотр всех 396 PNG вручную не заявляется. Окончательная визуальная приёмка остаётся за пользователем.

Исторические доказательства этапа A в `type02-reference/` не перезаписываются и не объявляются доказательствами текущего этапа B. Следующий коммит публикует только документы и CI-доказательства; проверенный рабочий код остаётся тем же.

## Границы приёмки

200% проверяется через эквивалент 1280 физических / 640 CSS px / DPR 2, с корректной работой media queries; ручное масштабирование браузера не заявляется. Нативная дата зависит от локали Chromium. Прежняя непереведённая ошибка охвата сертификата в EN/KK фиксируется сравнением с базой; локализация в TYPE-02 не меняется. 13 исторических online-import падений не закрываются этим PR.

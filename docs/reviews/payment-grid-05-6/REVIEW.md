# C5-6 — владелец базовой сетки способов поддержки

База: принятый #256 (`5e2b37431948f7d866ba18809d45bda4ddc74d05`).
Три точных правки `nomad360_calculator_ui.css` снимают два переопределения,
не меняя ни одного действующего представления. UI CSS уменьшается на **95 B**.

## Границы и фактические представления

| Представление | Сохранённый layout |
| --- | --- |
| Main с IRBIS-композицией | 1 колонка, margin-top 16px, gap 0, раскрывающиеся способы |
| US demo / настоящий standalone | 2 колонки выше 900px, 1 до 900px включительно, margin-top 20px, gap 12px |

Ранние `3 columns / 28px` были безусловно перекрыты поздней базой. Каноническая
база теперь определена один раз в исходном правиле; оставлено одно мобильное
правило до 900px. В общей мобильной группе удалён только fiat-selector, siblings
crypto/products/meta и их значения сохранены. Специфичная IRBIS-оболочка не
удаляется и не заменяется базовой сеткой. Провайдеры, адреса/реквизиты, телефоны,
ссылки, локали, copy handlers, фон/логотип/Inter и финансовые формулы не меняются.

DOM/метаданные принадлежат прежнему `nomad360_header.js / payFiat`, layout —
scoped `.nomad-pay-fiat` в исходном UI CSS, композиция main — IRBIS-модулю,
paint — прежней палитре. Глобальных новых классов и JS-обработчиков нет.
[Точные три edit-пары](../../../tests/fixtures/payment-grid/edits.json).

Свежий неизменённый AST-анализатор сырых исходников: **185 → 183**,
владелец сетки **2 → 0**. 19 проверенных групп C5-5 сохраняются; **164 ещё не
проверены**. [Владельцы и весь остаток](ownership.json). C5 не закрыта целиком.

## Исторические контракты

Прежние ожидаемые строки/SHA, отрицательные проверки, финансовые оракулы и
workflow сохранены. Два старых direct-source чтения получают лишь точную
нормализацию согласованного CSS, без изменения эталонов.
Тестовые адаптеры узнают только конкретные CSS-байты/размеры/SHA и точные
согласованные мосты старых comparators. Добавочные 95 B считаются ровно один
раз, отдельно от старой base64-экономии C5-2. Неверные шрифты, логотип, цвета,
границы, margin, лишний HTML и неизвестные resource SHA отклоняются.

Историческая C5-5 проверка продолжает свой контракт: известный UI diff
восстанавливается для старого census/source gate, что явно помечено в коде и
CLI log. Её 185/166 — исторические значения, а не новый сырой счётчик. Для
реального состояния используются только C5-6 raw 183 / retained 19 / unreviewed 164.
В C5-5 упаковке `standaloneIdentical` теперь честно false; совпадение проверяется
после только точного grid-restoration и помечено `normalizedHistoricalStandalone`.

L0-инвентаризация восстанавливает только этот geometry-only diff перед
сканированием UI CSS. Это сохраняет прежние text IDs/offsets; содержимое,
словари и переводы не меняются, неизвестный CSS не допускается. Финальные CI
проверяют реальные модели/restore/repeated navigation, Excel/OOXML и PDF;
их статусы финального HEAD публикуются в PR отдельно от локальных квитанций.

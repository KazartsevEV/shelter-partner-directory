Удалены **только две декларации** в `nomad360_calculator_ui.css` (`−60 B`):
1. `.nomad-embed-b2b-logo-mask img`: ранний `object-fit:contain`, перекрытый принятым `object-fit:cover` в общей маске логотипа TASK-10.

**Цветовые значения и тень оставлены без изменений.** Генератор `nomad360_palette.css` использует даже встречающиеся в нецветовых CSS-свойствах цветовые токены для своих селекторов и не должен измениться. Ни шрифты/графика/DOM/JS/числа/экспорт, ни состояние формы/платёжная логика не меняются.

`tests/c5_8_ui_scope.test.cjs` требует точного утверждённого преобразования исходного CSS и абсолютного равенства всех конечных значений CSS cascade. `tests/c5_8_ui_browser.cjs` сравнивает geometry/full computed styles двух реальных HTML × пять ширин × RU/EN/KK (30 пар). Исторические source/resource guards через `tests/helpers/c5-8-scope.cjs` могут нормализовать только эти два точных байтовых преобразования. Финансовые/VAT эталоны сохраняются, palette `--check` обязателен.

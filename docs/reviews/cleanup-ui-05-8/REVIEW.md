# C5-8 — перекрытые декларации UI CSS

База: принятый main `050bce789259867096d2d312e5b0dbea51454d5d` (PR #258).

## Объём
Из `nomad360_calculator_ui.css` удалены шесть ранних деклараций:
- `.nomad-embed-b2b-logo-mask`: `background:#fff`, `box-shadow:0 6px 22px ...`; действующий владелец — scoped объединённое правило логотипов TASK-10.
- `.nomad-embed-b2b-logo-mask img`: `object-fit:contain`; действующий — TASK-10 `cover`, без смены картинки.
- `body #nomad360-seo-banner.nomad-seo-banner` в `max-width:600px`: ранние 64px сетки перекрывались последующим 88px.
- `.nomad-seo-logo-mask`: `background:#fff`; действующий — белый фон общего правила масок логотипов.
- `.nomad-seo-tagline span+span`: устаревший цвет `#ed8e63`; действующий цвет `#FF913F`.

Удалено ровно **173 байта** исходного CSS. Финансовые движки, DOM, переводы, изображения, логотип, ZIP/сборка, палитра и JavaScript не меняются.

## Защитные проверки
- `tests/c5_8_ui_scope.test.cjs`: исходный базовый CSS сверяется с ровно пятью разрешёнными текстовыми преобразованиями; конечные победившие `selector/context/property/important` в PostCSS должны совпасть.
- `tests/c5_8_ui_browser.cjs`: в одном Chromium до/после сравниваются полный computed style, geometry, text и видимость затронутых элементов для двух реальных HTML × 5 ширин (320/390/600/601/1280) × RU/EN/KK, то есть 30 маршрутов и 60 загрузок.
- `c5-8-ui.yml`: числовые и налоговые эталоны, парные браузерные проверки.
- Контракт `file://` Issue #260 — отдельный открытый дефект, не заявляется исправленным.

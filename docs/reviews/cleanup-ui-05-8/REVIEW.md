# C5-8 — три строго перекрытые геометрические декларации

База: принятый main `050bce789259867096d2d312e5b0dbea51454d5d`, PR #258.

## Изменения
В `nomad360_calculator_ui.css` устранены исключительно три ранние декларации:
1. `.nomad-embed-b2b-logo-mask`: `box-shadow` раньше задавал тень, но поздний владелец общего правила логотипов TASK-10 задаёт `none`. Ранний фон `#fff` **сохранён**: он участвует в генерации палитры.
2. `.nomad-embed-b2b-logo-mask img`: `object-fit:contain` всегда перекрывается поздним `cover` TASK-10; фактический crop сохраняется.
3. `body #nomad360-seo-banner.nomad-seo-banner` внутри `max-width:600px`: ранняя колонка `64px` перекрывается поздней `88px` в том же media-контексте и с тем же selector/priority. Ширины у границы 600/601 проверяются.

Точное сокращение исходного CSS: **98 байт**. Никаких изменений финансовой математики, JS, HTML, палитры, изображений, шрифтов или данных нет.

## Сохранение старого тестового контракта
Существующие frozen source guards не переписываются под новые данные. В `tests/helpers/c5-8-scope.cjs` добавлен fail-closed точный мост: допускает только три утверждённых CSS-преобразования, восстановление полного исходного CSS при сравнении исторического baseline и нормализацию `SHA/bytes` CSS при проверке автономной сборки. Это не production-модуль.

`tests/c5_8_ui_scope.test.cjs` проверяет точный diff и все свойства-победители CSS cascade через PostCSS. `tests/c5_8_ui_browser.cjs` выполняет парные Chromium проверки реальных Marketing_calc.HTML и US_Retail_Demo.HTML на 320/390/600/601/1280, RU/EN/KK (30 пар). CI также запускает замороженные финансовые/налоговые тесты. `nomad360_palette.css` должен оставаться byte-identical и проходить штатный `--check`.

Старые цветовые CSS-значения, участвующие в генерации палитры, сознательно оставлены: механическое удаление изменило бы generated palette. Остальные группы не считаются автоматически мёртвыми. C5 пока открыт; дефект V1 `file://` из Issue #260 также остаётся вне C5.

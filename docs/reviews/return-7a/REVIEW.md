| Платформа | Действия пользователя |

| iOS | После добавления найти значок Nomad360 на экране «Домой» iPhone → коснуться значка. В дальнейшем открывать калькулятор этим же значком. |
| Android | После добавления найти значок Nomad360 на главном экране телефона → коснуться значка. В дальнейшем открывать калькулятор этим же значком. |

## Возврат к калькулятору

Единый `#nomad360-return` вставляется непосредственно перед `#nomad360-support` в существующем footer. Прежние «О проекте» и контакты перед footer сохранены на месте. Видимость блока не зависит от результатов или заполнения формы. Картинка не создавалась: по ТЗ до утверждения владельцем используется чистый текстовый блок.

RU, дословно: «Возвращайтесь к нам с новыми идеями!», три заданные кнопки Windows/iOS/Android, затем двумя отдельными крупными строками «У Nomad360 пока нет мобильного приложения.» и «Мы растем на ваши деньги.». EN/KK — предложенные в ТЗ переводы. На desktop кнопки в ряд, на мобильном колонкой; оффер калькулятора не менялся.

- **Windows:** реальный `Nomad360-lite.url`, MIME `text/plain;charset=utf-8`, ровно секция `[InternetShortcut]` и HTTPS URL оригинального калькулятора с текущим `lang`. Данные модели и прочие параметры не передаются. После клика доступна инструкция переноса файла и ручного создания ярлыка; статус успешного размещения не выдумывается.
- **iOS:** доступная инструкция браузера «Поделиться → На экран Домой → Добавить», включая опциональный Open as Web App и путь из встроенного браузера. Никаких файлов, профилей или ложного подтверждения установки.
- **Android:** только реально полученный `beforeinstallprompt` и клик пользователя могут вызвать `prompt()`. Без события/на другой ОС — инструкция. Accept, dismiss, ошибка и `appinstalled` обработаны отдельно. Подтверждение установки показывается только после `appinstalled`; принятие запроса им не считается. Обработана также гонка, когда `appinstalled` приходит раньше `userChoice`.
- **Справка:** один native dialog, доступный заголовок, Tab/Shift+Tab внутри, Escape/кнопка закрытия, возврат к свежей кнопке после смены языка. Платформа, порядок шагов и допустимая позиция прокрутки сохраняются. При недоступном clipboard можно выделить и скопировать адрес вручную.

## Manifest и границы установки

Manifest `nomad360.webmanifest` задаёт реальные name, id, start_url и scope внутри project path, использует неизменённый утверждённый PNG 1024×1024. Метаданные подключаются только модулем возврата. **Выбран `display: browser`:** это безопасный браузерный ярлык; установленный standalone-режим на настоящих устройствах здесь не проверен.

По проверенной документации MDN автоматическое предложение установки Chromium требует соответствующего display и иконок 192/512. В этом PR используются оригинальная иконка 1024 и браузерный fallback; **доступность системного prompt на опубликованном сайте не обещается**. Условная обработка события проверена симуляцией, не выдаётся за настоящую установку. Новый service worker, кэширование страниц, трекинг и офлайн-обещания не добавлены. SHELTER не затронут. [Проверенные источники](sources.json).

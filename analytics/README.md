# Nomad360: посещения, уникальные IP и сессии

В GitHub Pages нет серверного доступа к IP посетителя. Для реального счётчика используется отдельный Cloudflare Worker с D1. Пока Worker не опубликован, под кнопкой в подвале показывается **«Статистика пока недоступна»**. Нули никогда не подставляются вместо отсутствующих данных.

## Показатели
Три независимых периода: **сегодня** (календарный день Asia/Tbilisi), **последние 24 часа**, **последние 7 × 24 часов**. Для каждого: уникальные IP (хешированные сервером), новые IP (первое посещение за всю историю приходится на период), число уникальных сессий. Сессия меняется после 30 минут неактивности в одной вкладке. Переход на другую вкладку создаёт новую сессию, но не новый IP. Метрики не равны количеству людей: общий Wi-Fi/NAT может объединять разных людей, VPN/смена IP разделять одного посетителя.

## Публикация — требуется доступ к Cloudflare
1. Создать D1 БД: `npx wrangler d1 create nomad360-traffic`.
2. Скопировать `wrangler.example.toml` в `wrangler.toml`, вставить реальный `database_id`.
3. Создать таблицы: `npx wrangler d1 execute nomad360-traffic --remote --file=./schema.sql` из папки `analytics`.
4. Задать секрет (не коммитить его): `npx wrangler secret put IP_HASH_SECRET`. Используйте случайную строку не менее 32 байт; при замене секрета история уникальных IP перестанет сопоставляться.
5. `npx wrangler deploy` из `analytics`. Проверить GET `/stats` и POST `/visit` с Origin: https://kazartsevev.github.io.
6. В основном HTML перед `nomad360_traffic.js` установить `window.NOMAD360_TRAFFIC_ENDPOINT='https://<реальный-workер-URL>'` через конфигурацию развертывания и опубликовать калькулятор. В исходнике URL намеренно не выдуман.

Посещения регистрируются **только на официальном домене калькулятора**. Скачанные для других сайтов HTML-копии не добавляют чужой трафик в показатели основного сайта. Пользовательские расчёты, формы, cookies и прочие поля на сервер не пересылаются. Ретеншн событий — 90 дней; хеши исторических IP хранятся для правильного определения нового/повторного адреса. На публичном сайте нужно отразить обработку псевдонимизированных IP в политике конфиденциальности перед включением телеметрии.

### Проверка
Если Backend ещё не подключён, отображается честный текст о недоступности статистики; значения не выдумываются. Нельзя включать счётчик, направляя его на рекламные пиксели или API, возвращающие только pageview без уникальных IP: это другие показатели.

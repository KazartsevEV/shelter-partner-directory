# UNIFIED-BANNERS-01 scenery

Decorative assets only. All copy, controls, numbers, disclosures and payment UI remain live DOM.

- `hero.webp`: text/logo/panel-free reconstruction of the owner's `docs/approved-design/unified-banners/hero-desktop-reference.webp`; same blue mountains, orange sun and winding river/road.
- `about.webp`: byte-identical copy of the approved `about-moon-scenery.webp` (cold white moon / Mangyshlak).
- `support.webp`: text/control-free reconstruction of `support-desktop-reference.jpg`; same irbis, long fully visible tail, white snow and cold waterfall.
- `consulting.webp`: text/control-free reconstruction of `consulting-desktop-reference.webp`; same two Alatau rams and touching horns.

The three text-removal reconstructions use the image generation/edit tool; WebP encoding at quality 86 is a delivery optimization, not a new scene. Original references are unchanged. Total payload ≈ 767 KiB, all same-origin, cached across locales; the original wolf PNG is reused, never copied into a new logo asset. Portable HTML bundles these four images as data URLs.

Mobile places scenery outside text where necessary for contrast and keeps both animals and their identifying features. These deliberate composition adaptations are documented in the review, not represented as pixel-identical copies of the references.

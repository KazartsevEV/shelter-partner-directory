# Nomad360 banner scenes

`*-wide.webp` (desktop, full banner width) and `*-mobile.webp` (right part of the same scene) are built from the approved
references in `docs/approved-design/unified-banners/`: the text, plates and buttons baked into each reference were removed
(inpainting), nothing else was repainted, so the scene, objects and palette are the reference's own.
Text, cards and buttons on the banners are live HTML/CSS (translatable); the scenes carry no text.
Edges are feathered into the page navy `#173B58` by CSS masks only.
